# EpicWing

I build **EpicWing**, a self-hosted server management panel with a small Go agent. Game servers and other services run in isolated Docker containers.

- Repository: [EpicWing/epicwing-panel](https://github.com/EpicWing/epicwing-panel) (MIT, beta)
- Chat: [Discord](https://discord.gg/tc7xtNPsmh)

Feedback and bug reports are welcome in the repository's Issues and Discussions.
